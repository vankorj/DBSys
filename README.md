# DBSys Food Distribution System

## Purpose
This project is a full-stack ASP.NET Core web application designed to manage food distribution logistics, including vendors, orders, and distribution locations.

## Features
- CRUD operations for database entities
- Dynamic frontend using JavaScript
- SQL Server backend
- Filtering and sorting capabilities

## Tech Stack
- ASP.NET Core Razor Pages
- SQL Server
- JavaScript (modular frontend)
- Bootstrap (planned)

## Project Structure
- /Pages → UI
- /wwwroot → Static assets
- /database → SQL scripts
- /docs → Planning and documentation
